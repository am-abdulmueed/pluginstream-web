🔌 PluginStream — Extension & Repository Setup Guide

Follow these quick steps to set up all repositories and download extensions in PluginStream.

🌐 pluginstream.pages.dev
  1. 1
    Open Extensions Panel
    Go to app Settings (⚙️). Scroll down and select the Extensions tab.
  2. 2
    Open Repository Menu
    Tap the + Add Repository button at the bottom-right corner.
  3. 3
    Enter Shortcode
    In the "Repository URL or Shortcode" input field, enter:
    Shortcode pluginstream
    ℹ️ Note: Case-insensitive (works in uppercase or lowercase).
  4. 4
    Confirm Repository
    Tap "Add repository". Confirm by tapping "Add repository" again on the popup prompt.
  5. 5
    Wait for Auto-Index
    A toast notification "20 repositories added" will appear once loading completes.
  6. 6
    Download Plugins
    Tap any Repository Card to expand its available plugins. Click the Download (⬇️) button next to any plugin to install it.
💡
Tip: Once installed successfully, the download icon will change to a Checkmark (✅). 🌐 Website: Visit pluginstream.pages.dev for more information and updates.
